# Linux Permissions

## Permission Types

r = read 
w = write 
x = execute

## permission groups 

user = file owner
group = users belonging to the file's group
other = everyone else

## Example

-rwxr-xr-

user:
rwx

group:
r-x

other:
r--

## chmod

chmod +x script.sh

adds execyte permission to a file

## Running scripts

./script.sh
